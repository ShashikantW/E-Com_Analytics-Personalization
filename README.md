E-commerce Customer Growth Analytics and Personalization

#Project Overview
This project is an end-to-end data science pipeline designed to analyze customer behavior for a Brazilian e-commerce platform. By processing over 100k records, the system performs RFM (Recency, Frequency, Monetary) Segmentation to identify high-value customers and predict churn risk.

#Tech Used
Language: Python (Pandas, NumPy)

Database: MySQL (Relational Data Storage)

Visualization: Power BI (Interactive Dashboards)

IDE: VS Code / Jupyter Notebook

#Key Features and Analysis
Data Cleaning: Automated script to handle 3,800+ date formatting errors and missing values to ensure 100% dashboard accuracy.

RFM Segmentation: Categorized customers into Champions, Loyal, Big Spenders, and At-Risk groups using quintile scoring.

Churn Prediction: Identified that 40.18% of the customer base is at high risk of churning.

Product Recommendation: Developed a Top Category engine to suggest products based on segment-specific purchasing habits.

#Business Impact (KPIs)
Total Revenue Analyzed: $20.31 Million

Total Unique Customers: ~95,000

Key Insight: Retaining At-Risk customers could potentially save thousands in customer acquisition costs.
